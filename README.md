# Stress Prediction XAI

## Overview

Stress Prediction XAI is a machine learning research project that aims to predict stress levels among Sri Lankan university students using demographic, lifestyle, academic, behavioural, social media, and psychological factors. The project also integrates Explainable Artificial Intelligence (XAI) techniques to improve the transparency and interpretability of the prediction results.

---

## Research Objective

To develop and evaluate an Explainable Artificial Intelligence (XAI)-based framework for predicting stress levels among Sri Lankan university students and identify the factors that influence stress prediction.

---

## Features

- Data preprocessing
- Feature engineering
- Stress prediction using machine learning
- Explainable AI (SHAP)
- Model evaluation and comparison

## Machine Learning Models

- Logistic Regression
- Support Vector Machine (SVM)
- Random Forest
- XGBoost

---

## Explainability

The final model will be interpreted using SHAP (SHapley Additive exPlanations) to explain how each feature contributes to the predicted stress level.

---

## Dataset

The dataset consists of demographic, lifestyle, academic, behavioural, social media, and Perceived Stress Scale (PSS-10) responses collected through a structured Google Form questionnaire.
